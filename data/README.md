# 数据来源与使用说明

本项目使用 Titanic 乘客数据：`train.csv` 包含 891 条有标签记录，`test.csv` 包含 418 条无标签记录。文件由既有课程项目复制到本目录，原文件不被改写。

既有项目的数据来源为 [Heywhale 数据页面](https://www.heywhale.com/mw/dataset/5f69d01971c700003078960e/file)。本说明记录来源，数据授权与署名要求以原发布方声明为准；本项目不为原数据补充或变更许可证。

## 原始字段

| 字段 | 含义 | 本项目用途 |
|---|---|---|
| PassengerId | 乘客编号 | 对应记录和预测，不进入分类器 |
| Survived | 0 未生存，1 生存 | 目标标签，仅训练文件具备 |
| Pclass | 舱位等级 1、2、3 | 类别特征；用于年龄与票价处理 |
| Name | 姓名 | 提取称谓类别 |
| Sex | 性别 | 类别特征 |
| Age | 年龄 | 三种缺失处理方案；数值特征 |
| SibSp | 同行兄弟姐妹及配偶数量 | 构造家庭类别、预测年龄 |
| Parch | 同行父母及子女数量 | 构造家庭类别、预测年龄 |
| Ticket | 船票编号 | 保留原数据，本次最终分类器未使用 |
| Fare | 票价 | 按舱位中位数填充；数值特征 |
| Cabin | 舱号 | 转换为是否存在舱号记录 |
| Embarked | 登船港口代码 | 众数填充和类别编码 |

`HasCabin=0` 只表示舱号记录缺失，不表示没有舱位。`FamilySize=SibSp+Parch+1` 表示数据记录的同行家庭规模。称谓组合是建模类别，不能把 `Child` 等同于所有儿童，也不能将合并后的 `Officer` 全部解释为军官。

## 数据范围约定

- 891 人按分层随机划分分为 712 人训练部分和 179 人留出部分，随机种子为 42。
- 详细关联分析与模型选择使用训练部分；年龄分组分析保留原始年龄缺失组。
- 每折预处理规则只从当前折训练数据学习。
- 留出部分只作最终评估和描述性错误分析。
- 方案确定后用全部 891 人重新训练，预测 418 人。
- 测试预测的 0、1 是模型输出，没有测试真实标签，不能由这些输出计算准确率。

`artifacts` 中的训练子集、评估和预览文件均为这些原始数据的派生结果。新项目已经完成训练复现：留出部分149/179人预测正确；418条测试预测与原项目CSV逐行一致，其中171人预测生存、247人预测未生存。
